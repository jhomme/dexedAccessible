# DexedAccessible key bindings

## Windows

- Focus on operator 'X' group: Control+1 to Control+6
- Toggle active operator 'X': Control+SHIFT+1 to Control+SHIFT+6
- Focus on global group: Control+G
- Focus on the on-screen keyboard to play notes from the computer keyboard: Control+K
- Open cartridge manager: Control+L
- Open parameter dialog: Control+P
- Announce the algorithm routing description from anywhere, without moving focus:
  Control+SHIFT+A
- Move keyboard focus to the next or previous control, announcing the panel's name when
  focus crosses into a different one: TAB or SHIFT+TAB
- Jump to the previous panel (an Operator, Global Parameters, or the on-screen keyboard),
  landing on its first control, wrapping around at either end: COMMA
- Jump to the next panel the same way: PERIOD
- On any slider, step by 1, Up, Down, Left, and Right arrows
- On any slider, step by 5: SHIFT+RIGHT, Left, Up, and Down  arrows
- In the cartridge manager's program lists, move to a sound and load it: RIGHT, LEFT, UP, or
  DOWN arrows
- In the cartridge manager's program lists, load the highlighted sound: RETURN
- In the cartridge manager, move between whole sections, the file browser, the sound-browsing
  list, the active list, and each button, rather than one sound at a time: TAB or SHIFT+TAB
