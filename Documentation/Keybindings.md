# Dexed key bindings

Most of these are confirmed working in the Standalone app. Some interfere with Logic Pro,
since Logic has its own uses for several of the same keys and intercepts them before Dexed
ever sees them. If a key doesn't do what's listed here while running inside Logic, try it in
Standalone instead to confirm whether it's Dexed or the host getting in the way.

- Focus on operator 'X' group: CTRL+1 to CTRL+6
- Toggle active operator 'X': CTRL+SHIFT+1 to CTRL+SHIFT+6
- Focus on global group: CTRL+G
- Open cartridge manager: CTRL+L
- Open parameter dialog: CTRL+P
- On any slider, jump to the lowest value: HOME
- On any slider, jump to the highest value: END
- On any slider, add 5 to the current value: SHIFT+RIGHT or SHIFT+DOWN
- On any slider, subtract 5 from the current value: SHIFT+LEFT or SHIFT+UP
- On any slider, step by 1, Down moves the value up and Up moves it down: RIGHT, LEFT, UP, or
  DOWN
- In the cartridge manager's program lists, move to a sound and load it: RIGHT, LEFT, UP, or
  DOWN
- In the cartridge manager's program lists, load the highlighted sound: RETURN
- In the cartridge manager, move between whole sections, the file browser, the sound-browsing
  list, the active list, and each button, rather than one sound at a time: TAB or SHIFT+TAB
